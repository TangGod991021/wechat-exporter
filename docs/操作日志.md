### 修复双击 exe 无反应

- 现象：双击 `dist\微信聊天记录导出\微信聊天记录导出.exe`，无窗口、无报错，约 20 秒后进程消失；命令行带输出重定向启动则正常
- 根因：PyInstaller 窗口模式（`console=False`）下 `sys.stdout/stderr` 为 `None`；uvicorn 初始化日志时调用 `sys.stdout.isatty()` 抛异常，异常发生在后台线程中被吞掉，`wait_server` 超时后进程静默退出
- 修复：`app/main.py` 启动时用 `devnull` 兜底标准输出/错误流；uvicorn 线程异常会被捕获并合并进启动错误；启动失败时写入 exe 同级的 `启动错误.log` 并弹出错误对话框
- 重新打包并验证：模拟资源管理器启动（`Start-Process` 无输出重定向）窗口正常显示、服务正常监听、24 秒后仍在运行、首页返回 HTTP 200
- 补充 README / USAGE 的「双击无反应」排查说明
