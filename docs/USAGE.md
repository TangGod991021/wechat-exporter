# 使用说明

## 0. 便携版运行（复制到其他电脑）

1. 把整个 `WeChatExporter` 文件夹复制到目标电脑（不要只复制 exe）
2. 双击 `WeChatExporter.exe`
3. 首次运行会在 exe 同级目录生成 `config.json`、`data\`、`media\`、`exports\`

要求：Windows 10/11 + WebView2 运行时（Win11 自带）。FFmpeg 已内置在 `_internal\ffmpeg\`，启动时自动加入 `PATH`，无需另外安装；导出默认写入 exe 同级的 `exports\`（配置中保存为相对路径 `exports`，移动文件夹后仍有效）。

## 1. 启动前准备

1. 登录微信 4.x，并保持运行
2. 确认微信数据目录存在（默认 `C:\Users\<用户>\Documents\xwechat_files`）
3. 图片 / 视频处理所需的 FFmpeg 已随包提供，无需安装

## 2. 五步流程

### 第一步：选择账号

- 程序会自动扫描数据目录并列出账号
- 如果未找到（例如改过微信的存储路径），点击「Everything 查找」：
  - 程序已内置 [Everything](https://www.voidtools.com/zh-cn/) 便携版（`_internal\everything\`），无需另行安装
  - Everything 未运行时会自动静默启动：不弹窗、不占任务栏、不弹 UAC，仅在托盘保留图标；随后通过 `es.exe` 秒级搜索 `db_storage` / `xwechat_files` 并自动填入数据目录
  - 首次启动需要几秒钟建立索引；索引文件保存在 `_internal\everything\Everything.db`，之后查询是即时的
  - 程序退出时会自动关闭由它启动的 Everything 实例，不影响你自行安装/运行的 Everything
  - 若内置文件缺失，会回退为本地扫描（常见目录 + 各盘符下与微信相关的目录）
- 也可以点击「选择数据目录」手动指定 `xwechat_files` 所在目录，或选择它的上级目录：程序会在所选目录内递归查找含 `db_storage` 的账号文件夹

### 第二步：提取密钥

- 从运行中的微信进程读取 SQLCipher 密钥
- 同时建立会话索引：解密 `session.db` / `contact.db`
- 微信只需在这一步保持登录，后续步骤可离线执行
- 如果之前已提取过密钥，可点击「建立会话索引」跳过再次读取内存

### 第三步：选择会话

- 进入本步时会自动解密 `message_0.db` / `media_0.db`，加载消息条数（首次约 1–3 秒）
- 支持按群名、备注、昵称、wxid 搜索
- 「群聊 / 私聊」筛选
- 点击会话可预览最近消息（支持引用、聊天记录展开等）
- 勾选一个或多个会话

### 第四步：准备数据

只处理所选会话实际引用的媒体：

- 图片：解密 `.dat` 并转换 WxAM
- 语音：SILK → WAV
- 视频：HEVC → H.264
- 表情：按消息里的腾讯 CDN 地址下载并缓存到 `media/<账号>/stickers/`
- 附件：不会在准备阶段复制，导出时再从 `msg/file` 定位并复制

未选中的会话不会被处理；已处理过的媒体按 mtime 跳过。等待进度完成后进入下一步。

> 步骤条支持点击回退；已完成的步骤可随时回看。修改所选会话后，需要重新执行第四步。

### 第五步：导出

- **格式**：默认只勾选 HTML，可按需添加 TXT / JSON / CSV
- **时间范围**：留空表示全部
- **导出方式**：
  - `归档文件夹（推荐）`：每个会话一个文件夹，媒体自动复制，可离线打开
  - `仅引用本机文件`：速度快，但移动目录后媒体失效

## 3. 导出结果

```
exports/导出_20261113_1200/
├── manifest.json
└── 群聊名称/
    ├── index.html
    ├── 聊天记录.json
    ├── 聊天记录.csv
    ├── 聊天记录.txt
    ├── images/
    ├── videos/
    ├── audio/
    ├── files/
    └── manifest.json
```

- HTML 中图片、视频、语音、附件均使用相对路径
- 图片、表情可点击放大预览，按 `Esc` 或点击空白处关闭
- 文件附件点击后打开或下载；语音提供「下载语音」
- 链接、引用里的链接、转发记录里的链接均可在新窗口打开
- 转账/红包卡片显示金额、备注与状态
- 整个文件夹可以复制到 U 盘或其他电脑直接查看
- `manifest.json` 记录消息数、媒体统计与文件清单

## 4. 常见问题

### 视频有进度条但画面不动

视频源为 HEVC（H.265），浏览器默认不解码。第四步「准备数据」会自动把所选会话中的 HEVC 转码为 H.264；请确认第三步已选中该会话并重新执行第四步。

### 导出缺少历史消息（只剩较新的记录）

微信 4.x 会把同一会话的消息滚动写入 `message_0.db`、`message_1.db` 等多个分库。0.2.1 起会合并全部分库；如果仍缺少：

- 回到第 2 步查看是否有「消息库缺少密钥 / 解密失败」提示；若有，点击「重新提取密钥」
  （微信新增分库后，旧密钥文件不会自动包含它）
- 确认「准备数据」步骤的日志里没有消息库解密失败记录
- 对比会话列表中的消息数是否与微信客户端接近

### 提取密钥失败

- 确认微信已登录且正在运行
- 如果微信版本较新，可能尚未适配，请提交 Issue 并附上微信版本号

### 链接打开显示 `{"code":-404,"message":"啥都木有","ttl":1}`

这是 B 站对**失效短链/已删除视频**的返回。可把地址直接粘贴到浏览器验证：
去掉导出程序附加的所有参数后仍返回该 JSON，说明链接源已失效，导出程序无法恢复。
0.3.4 起会先清理 `&amp;amp;`、`&lt;/url&gt;` 等多次转义残留，避免“本来有效但被转义坏”的情况。
准备/导出时会自动检测 B 站短链：

- 有效短链：转换为 `https://www.bilibili.com/video/BV...` 直链
- 失效短链：卡片点击改为按标题搜索，并显示「原短链已失效」
- 视频卡片下方有「📋 复制标题」「搜索标题」「原短链」入口

### 分享链接点击没有反应

链接卡片、B 站/小红书等视频分享、小程序和音乐卡片都支持整卡点击。界面预览会调用
系统默认浏览器打开；若没有反应，请确认系统已设置默认浏览器，或直接复制卡片中的
网址到浏览器。导出 HTML 中链接使用普通 `<a target="_blank">`，由浏览器处理。

### 图片 / 视频显示「已过期或已被清理」

微信只缓存查看过的媒体。原图不在本地时，聊天记录会明确显示：

- `[图片]（图片已过期或已被清理）`：本地没有任何图片文件
- `[图片]（原图已过期或已被清理，显示缩略图）`：本地只有 `_t` 缩略图
- 语音/视频缺失同样标注

这是微信自身的缓存状态，不是导出失败；手机微信里通常也会显示过期提示。

### 表情显示「[表情未下载]」

本地表情缓存是加密格式，程序按消息里的腾讯 CDN 地址下载。若显示该提示，
请检查网络，或重新执行第四步「准备数据」；链接失效的表情无法恢复。

### 附件显示「附件未缓存到本地」

微信可能已清理该文件，或文件只存在于手机上。程序会在 `msg/file` 与
`msg/attach/**/F` 中按文件名、大小和时间匹配；匹配不到时只能标注缺失。

### 导出的 HTML 打开很慢

大群（数万条消息）的 HTML 文件较大，属于正常现象。可按时间范围分批导出。

### 双击 exe 没有反应

- 确认复制的是**整个程序文件夹**（必须包含 `_internal\`），不能只复制 exe
- 查看 exe 同目录是否生成 `启动错误.log`，里面记录了具体异常
- 确认目标电脑已安装 WebView2 运行时（Win11 自带，Win10 一般随 Edge 安装）
- 若被杀毒软件拦截，请添加信任后重试

### 杀毒软件误报

PyInstaller 打包的程序常见误报，请添加信任或使用源码运行。
