# 使用说明

## 0. 便携版运行（复制到其他电脑）

1. 把整个 `微信聊天记录导出` 文件夹复制到目标电脑（不要只复制 exe）
2. 双击 `微信聊天记录导出.exe`
3. 首次运行会在 exe 同级目录生成 `config.json`、`data\`、`media\`、`exports\`

要求：Windows 10/11 + WebView2 运行时（Win11 自带）。图片 / 视频处理需另外安装 FFmpeg 并加入 `PATH`。

## 1. 启动前准备

1. 登录微信 4.x，并保持运行
2. 确认微信数据目录存在（默认 `C:\Users\<用户>\Documents\xwechat_files`）
3. 如需要处理图片 / 视频，请安装 FFmpeg 并加入 `PATH`

## 2. 四步流程

### 第一步：选择账号

- 程序会自动扫描数据目录并列出账号
- 如果未找到，可点击「选择数据目录」手动指定 `xwechat_files` 所在目录

### 第二步：准备数据

按顺序或直接点击「一键完成」：

1. **提取密钥**：从运行中的微信进程读取 SQLCipher 密钥
2. **解密数据库**：把 20 个左右的数据库解密到本地独立目录
3. **解密图片 / 语音 / 视频**：
   - 图片：解密 `.dat` 并转换 WxAM
   - 语音：SILK → WAV
   - 视频：建立索引，HEVC 自动转 H.264（首次较慢）

> 步骤条支持点击回退；已完成的步骤可随时回看。

### 第三步：选择会话

- 支持按群名、备注、昵称、wxid 搜索
- 「群聊 / 私聊」筛选
- 点击会话可预览最近消息（支持引用、聊天记录展开等）
- 勾选一个或多个会话

### 第四步：导出

- **格式**：默认只勾选 HTML，可按需添加 TXT / JSON / CSV
- **时间范围**：留空表示全部
- **导出方式**：
  - `归档文件夹（推荐）`：每个会话一个文件夹，媒体自动复制，可离线打开
  - `仅引用本机文件`：速度快，但移动目录后媒体失效

## 3. 导出结果

```
exports/导出_20261113_1200/
├── manifest.json
└── 群聊名称/
    ├── index.html
    ├── 聊天记录.json
    ├── 聊天记录.csv
    ├── 聊天记录.txt
    ├── images/
    ├── videos/
    ├── audio/
    └── manifest.json
```

- HTML 中图片、视频、语音均使用相对路径
- 整个文件夹可以复制到 U 盘或其他电脑直接查看
- `manifest.json` 记录消息数、媒体统计与文件清单

## 4. 常见问题

### 视频有进度条但画面不动

视频源为 HEVC（H.265），浏览器默认不解码。请执行第二步的「解密图片 / 语音 / 视频」，程序会自动转码 H.264；重新导出即可。

### 提取密钥失败

- 确认微信已登录且正在运行
- 如果微信版本较新，可能尚未适配，请提交 Issue 并附上微信版本号

### 图片 / 视频显示「未缓存到本地」

微信只缓存查看过的媒体。未下载的内容无法离线还原。

### 导出的 HTML 打开很慢

大群（数万条消息）的 HTML 文件较大，属于正常现象。可按时间范围分批导出。

### 杀毒软件误报

PyInstaller 打包的程序常见误报，请添加信任或使用源码运行。
