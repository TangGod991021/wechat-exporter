# 隐私说明

## 数据流向

本程序默认**完全本地运行**：

- 不上传聊天记录、不遥测
- FastAPI 仅监听 `127.0.0.1`
- 唯一的联网行为是**下载表情图片**：微信本地表情缓存是加密格式，程序会读取
  消息 XML 中由腾讯提供的表情 CDN 地址（仅 `*.qq.com` 等腾讯域名）下载原图，
  并缓存到 `media\<账号>\stickers\`。请求内容只有表情地址和文件，不包含聊天内容；
  断网时表情显示为占位符。第 4 步「准备数据」或直接导出时触发。

## 本地数据位置

| 内容 | 默认位置 | 敏感性 |
|---|---|---|
| 配置 | `config.json` | 低（含最近账号文件夹名） |
| 数据库密钥 | `data\<账号>\keys.json` | **极高** |
| 解密数据库 | `data\<账号>\` | **极高** |
| 图片 / 语音 / 视频 / 表情缓存 | `media\<账号>\` | 高 |
| 导出归档 | `exports\` | 高 |

## 原始微信数据

- `xwechat_files` 下的数据**只读**，程序不会修改
- 所有解密、转码产物都写入独立目录

## 安全建议

1. 不要将 `data/`、`media/`、`exports/`、`config.json` 提交到 Git
2. 分享导出归档前，确认其中不含不愿公开的聊天内容
3. 不再使用时，删除上述目录即可彻底清理
4. `keys.json` 等同于账号数据钥匙，切勿发送给他人
5. 在公共电脑上使用后请及时清理

## 权限

- 读取微信进程内存需要与微信相同的用户上下文；通常无需管理员权限
- 若系统策略限制，可能需要以管理员身份运行

## 第三方

导出 HTML 中可能引用本地文件（归档模式下为相对路径）。使用 `file://` 打开时，
浏览器仅访问本地文件，不会联网。
